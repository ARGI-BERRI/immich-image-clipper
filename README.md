# Immich-Image-Clipper

An extension for Edge and Chrome that provides a feature to upload images to Immich easily (via right-click menu).
No rich features - it just uploads images to your image vault.

## Lint, Format, and Test

```sh
# It uses ESLint
pnpm run lint

# It uses Prettier
pnpm run format

# It uses vitest
pnpm run test
```
